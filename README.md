# HauyneLib

HauyneLib は、NeoForge / Forge 向けのライブラリ Mod です。コンフィグ機能を利用する Mod の開発には、KSP と `hauyne-config-ksp` が必須です。

現在セットアップ中です。公開バージョンと配布ファイルは [Releases](https://github.com/Lapis256/HauyneLib/releases) を参照してください。

公開 Maven リポジトリ: <https://maven.lapis256.dev>

## サポート対象

| Minecraft | ローダー |
| --- | --- |
| 26.1.2 | NeoForge |
| 1.21.1 | NeoForge |
| 1.20.1 | Forge |
